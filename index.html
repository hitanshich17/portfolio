Recipe 01 · Distributed systems

NextToSkin

A skincare recommender that turns a short quiz and your local weather into product picks.

In the oven

Ingredients

  • Java · Spring Boot
  • Python · FastAPI
  • Kafka
  • PostgreSQL
  • Redis
  • Nginx
  • Docker · AWS ECS
  • Testcontainers

Method

  1. Load 20K+ products through a validated, deduplicated ingestion pipeline.
  2. Publish product-updated events to Kafka, keyed by product ID so updates stay in order.
  3. Consume them in a consumer group with retries and a dead-letter topic.
  4. Cache picks with Redis cache-aside, invalidated by the same events.

Step 2

Press play to watch an event move through the system.

Every 3rd event in this demo is a bad payload, so you can see the retry and dead-letter path too.

Recipe 03 · Real-time collaboration

Voyago

A trip planner where a whole group edits the same itinerary, live.

Live sync

Ingredients

  • TypeScript · React
  • Node.js · Express
  • Kafka
  • WebSockets
  • MongoDB
  • Redis pub/sub
  • GitHub Actions

Method

  1. Express validates each edit and saves it to MongoDB.
  2. Kafka publishes it keyed by trip ID, so every trip’s edits stay in order.
  3. Consumers push it to clients over WebSockets.
  4. Redis pub/sub fans it out across 2 load-balanced instances.
Serves
4 editors, tested live
Ready in
150 ms median
Yield
one shared trip

Recipe 04 · Civic safety · Philly Codefest

Way2Go

Compares walking routes through Philadelphia by predicted safety, not just speed.

Ingredients

  • Python
  • XGBoost
  • Kernel density estimation
  • Next.js
  • Google Maps
  • ~43,000 police records

Method

  1. Train on ~43,000 Philadelphia Police Department records.
  2. Map where incidents cluster with kernel density estimation.
  3. Predict each route segment’s risk with XGBoost.
  4. Blend 0.65 × XGBoost + 0.35 × KDE into one route safety score.
